[Simple Icons](https://www.npmjs.com/package/simple-icons) **v16.38.1**
(CC0-1.0). GPUI paints each SVG in a single colour (`Hsla`), tinted with the
brand hex (lightened in the dark theme where needed for readability, notably
MariaDB `#003545`).
