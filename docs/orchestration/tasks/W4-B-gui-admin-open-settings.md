## Build

1. **Databases tab** (PostgreSQL now; MySQL and MariaDB light up when W4-A2 lands without GUI changes, because the surface is engine-neutral). Card "Database": table of name, owner, size from `list_databases`, "Buat database" (name field validated with the same allowlist message the core returns, no round trip for the obvious cases), "Hapus" per row opening a dialog that requires typing the database name (F-DBU-01 AC3; the confirm button stays disabled until the text equals the name; the dialog restores focus on close). Card "User & hak akses": create user (name, database, `Read-only` / `Read-write`), the generated password shown ONCE in a dialog with a Copy button and a clear "tidak akan ditampilkan lagi" note (F-DBU-02 AC2), never kept in view state after the dialog closes, never logged, never in a toast. Card "Password superuser": "Reset password" with a confirmation, the new URI shown once with Copy (F-DBU-03 AC1); a failed reset shows the typed error and states that the old password still works (F-DBU-03 AC2). Refresh on `ServiceEvent::AdminChanged` for the visible instance. An instance that is not running shows an empty state with a one-click Start, not a connection error; a no-password PostgreSQL and Valkey show the typed message the service returns (do not invent text, use the service error's user message). Every call goes through `service_bridge` off the GPUI thread; while a call is in flight the buttons show it and are disabled; a failure is a typed error in the card, not a panic and not only a toast.
2. **"Open in…" menu** in the instance header and the Overview "Connection" card: entries come from `detect_clients` (cached, with a refresh item), grouped GUI clients and CLI clients; selecting one calls `open_in_client`; when nothing is detected the menu shows "Salin URI" (F-OPN-01 AC2) instead of an empty list; a launch error is a typed message. No hover-only action. The disabled placeholder row from W2-E goes away.
3. **Settings dialog** (title bar gear, `Ctrl/Cmd+,`): section "Pembaruan" (current version, install kind, "Periksa sekarang", the result, "Pasang" only when `can_self_update`, otherwise the package-manager hint the service returns; progress and the typed error on failure; no timer and no check at startup unless the setting says so: the setting itself is out of scope, only a manual check) and section "Jalankan saat login" (F-AUT-01 AC1/AC2) using the W4-D autostart core API through the bridge, with the current status read on open and a typed error shown when enabling fails (do not show enabled after a failed enable). The per-instance "autostart" checkbox already exists on the Overview card; leave it.
4. **Strings**: all visible text in `crates/core/src/strings.rs`, Indonesian as the PRD writes it. **Accessibility**: text through `Label`; unique element ids per row and per dialog (the a11y duplicate-node assertion is the trap: derive ids from the instance id and the database or user name, test that two instances with the same database name do not collide); status is never colour alone; keyboard: Tab order follows the visual order, `Escape` closes the top dialog, `Enter` confirms only when the confirm button is enabled.
5. **Mock**: scripted scenarios in `service/mock` so the screens are testable and reviewable in the demo build (empty list, many rows, a slow call, a failed call, a reset failure, no clients detected, an update available, a package-manager install).
