# Trusted Ed25519 release-signing public keys for DBLocal.
#
# Each non-comment line is a 64-character lowercase hex string representing
# a raw 32-byte Ed25519 public key (matching TRUSTED_PUBLIC_KEYS in
# crates/core/src/update/verify.rs).
#
# Multiple keys may be listed during key rotation.
# While this file has no keys, tag builds in .github/workflows/release.yml
# fail closed and release builds refuse automatic self-update.
#
# To generate the key pair and upload the private key to GitHub Actions
# secrets without printing it, run:
#   bash packaging/release-signing/generate-key.sh
